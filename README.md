1. Что такое JSON и для чего он используется?
екстовый формат хранения и обмена данными между программами
2. Чем отличается `Serialize` от `Deserialize`?
первый преобразует элемент C# в JSON, а второй наоборот из JSON в С#
3. Почему результат `JsonSerializer.Serialize(...)` имеет тип `string`?
JSON - это текст, поэтому результат сериализации представляет собой строку
4. Как сохранить полученную JSON-строку в файл и затем восстановить из неё объект?
Для сохранения используется File.WriteAllText(), для чтения — File.ReadAllText(), а для восстановления объекта — JsonSerializer.Deserialize<T>()
5. Можно ли сериализовать `List<T>`? Что получится при сериализации списка объектов?
Получится JSON-массив, содержащий данные всех объектов списка.
6. Что произойдёт, если JSON некорректен или не соответствует ожидаемому типу?
Может возникнуть исключение JsonException, которое можно обработать с помощью try/catch
7. Почему JSON удобно использовать для хранения данных между запусками программы?
Потому что JSON можно сохранить в файл, а при следующем запуске прочитать его и восстановить ранее сохранённые данные.
